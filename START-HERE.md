# Harness Kit: start here

**From:** Courtney (and her Claude)
**For:** you, and your Claude
**Snapshot date:** 2026-09-28

## What this is

Out of the box, Claude Code is a brilliant stranger. It knows a lot, but starts off knowing next to nothing about you. It can't look up what you decided last month, a correction you make today may not make it to tomorrow, and it waits for you to start everything.

A **harness** is everything you put around Claude so it works like a colleague who's been with you for months: instructions it reads every session, facts it can look up, a record of past work it can search, a close-out routine that keeps those stores fed, worked-out methods for recurring jobs, scripts that block damaging moves, and a loop that turns each correction into something permanent.

Claude Code already has the sockets for almost all of this built in (CLAUDE.md, a rules folder, auto memory, skills, hooks). What it doesn't come with is what goes *in* them. That part is personal, and it's what this kit helps you build.

## Why it's a kit and not a copy of someone's setup

The first time this setup was handed to someone, it was a folder of files. The journal survived and nothing else did. A harness is half files and half habits, and copying files only moves the files. So this kit is a **bootstrap your Claude runs with you**: it interviews you, looks at what you already have, and builds *your* versions of the pieces that fit. Courtney's real files come along as worked examples, not as things to install.

## What's in the box

- **SEED.md:** the main event. The protocol your Claude follows, in short phases you can spread over a few sessions.
- **guide/:** written for your Claude, readable by you. How the pieces fit (`architecture.md`), why notes don't surface on their own (`retrieval.md`), and the habits that make the whole thing compound (`operator-practices.md`).
- **CATALOG.md:** every tool in the kit, tiered (start here / add when the moment comes), each with what it needs in order to actually work.
- **reference/:** real files from a working harness, lightly generalized: rules, memory examples, skills, commands, hooks, and the friction loop. Each is marked where it's personal calibration rather than general method.
- **CODEX.md:** a short adapter if you also use Codex and want it inside the same harness.

## How to run it

1. Unzip this folder somewhere you'll keep it.
2. Open Claude Code in any folder and say: **"Read START-HERE.md and SEED.md in `<path to this folder>`, then let's begin."**
3. Expect a conversation, not an install. The seed builds into your `~/.claude` folder (Claude Code's global config), which is where a harness lives. It's additive: it never overwrites or deletes anything you already have without showing you first.

**Read before you install, this kit included.** Skills, hooks and instructions change how an agent behaves on your machine. Your Claude should show you each file before it installs it, and you should say no to anything you don't understand yet.

## What it costs

- **A few sessions to set up.** The seed is paced so you can stop at the end of any phase and still be better off.
- **Upkeep.** Every always-on piece is read every session, so the harness needs pruning, not just adding. The seed sets a two-week check-in for exactly this.
- **Wrong rules get followed too.** A rule that describes you badly is obeyed as faithfully as a good one. Revisit them.

## How you'll know it worked

A month from now, a fresh session surprises you by knowing something from three sessions ago that you didn't re-tell it. And a correction you made once hasn't come back.
