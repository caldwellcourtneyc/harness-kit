Build your own Claude Code harness

Claude Code starts as a brilliant stranger.

It knows a lot, but starts off knowing next to nothing about you. It can't look up what you decided last month, today's correction may not make it to tomorrow, and it waits for you to start everything. A harness is what you put around it, so it works like a colleague who's been with you for months.

Get the kit

A set of plain text files your Claude reads and works through with you. It builds into your own Claude Code setup over a few short conversations, and never overwrites anything you already have without showing you first. It writes to Claude Code's settings folder in your home directory (~/.claude), so what it builds works in every project, and you can start it from any folder.

Download the kit (zip)

This harness can also work with Codex. The kit includes an adapter for it.

  1. Unzip it somewhere you'll keep it. It unzips as a folder called harness-kit-main.
  2. Open Claude Code and say: Read START-HERE.md and SEED.md in <the path to harness-kit-main>, then let's begin.
  3. Expect a conversation, not an installer. It starts by looking at what you already have and asking how you work, then builds these pieces roughly in the order above. Stop after any conversation and pick it up next time.
  4. Read each file before you add it. That includes this kit; your Claude shows you each one first.
What it costsA few sessions to set up, spread out however you like.
What it asks of youPruning. Every always-on piece is read every session, so the kit sets a two-week check-in to remove what hasn't earned its place.
How you'll know it workedA fresh session surprises you with something from three sessions ago that you didn't re-tell it.
